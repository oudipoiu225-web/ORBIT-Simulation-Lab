# فایل ORBIT

پسوند پیشنهادی `.orbit.json`. یک نمونهٔ کوتاه: `{"format":"orbit.simlab","version":1,"projects":[{"id":"...","name":"...","settings":{...},"nodes":[...],"links":[...],"rules":[],"inputs":[],"history":[]}]}`. قرارداد دقیق فیلدها در مدل‌های `domain/model/Project.kt` با Kotlin Serialization تعریف شده است. تمام فیلدهای اختیاری مقدار پیش‌فرض دارند. فیلد `kind` نوع شرط/عملیات sealed را مشخص می‌کند.

نسخهٔ تنها ۱ است. ورود به ۲ مگابایت، عمق JSON برابر ۳۲، تعداد پروژه حداکثر ۱۰۰ و حدود عناصر در Validator محدود می‌شود. فایل خراب، نسخهٔ ناشناخته، مقدار نامعتبر و شناسهٔ تکراری رد می‌شود. از مسیر درون JSON استفاده نمی‌شود؛ هیچ محتوا به عنوان کد یا سند اجرایی پردازش نمی‌شود. فایل معتبر پس از ورود با شناسهٔ تازه ذخیره می‌شود؛ شناسهٔ گره‌های داخل هر پروژه حفظ می‌شود و ارجاعات همچنان معتبر می‌مانند. خروجی پشتیبان همان قالب خروجی پروژه است و همهٔ پروژه‌ها را در یک فایل جای می‌دهد.
