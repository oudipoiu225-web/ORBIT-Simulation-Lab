# ORBIT Simulation Lab

آزمایشگاه شبیه‌سازی رویدادگسستهٔ آفلاین برای Android، نوشته‌شده با Kotlin/Compose. نمونهٔ «شبیه‌ساز صف اورژانس» کاملاً ساختگی است و برای تصمیم‌گیری درمانی نیست.

## Build / اجرا

پوشه را در Android Studio با JDK 17 باز کنید. Android SDK 35 نصب باشد. **Gradle 8.9** و Android Gradle Plugin **8.7.3**، Kotlin **2.0.21** لازم‌اند. Sync و سپس `:app:testDebugUnitTest :app:assembleDebug` را اجرا کنید. روی دستگاه Android 8.0+ اپ را نصب کنید. ابزار خط فرمان (اگر در PATH باشد): `gradle :app:testDebugUnitTest :app:assembleDebug`.

در GitHub Actions هر push به `main`، تست‌های JVM و APK اشکال‌زدایی را می‌سازد و آن را به عنوان artifact قرار می‌دهد. انتشار **فقط با tag** از نوع `v0.1.0` انجام می‌شود و به چهار Secret نیاز دارد: `ORBIT_KEYSTORE_B64`, `ORBIT_STORE_PASSWORD`, `ORBIT_KEY_PASSWORD`, `ORBIT_KEY_ALIAS`. Keystore پایدار شخصی را بیرون مخزن بسازید؛ آن را در مخزن قرار ندهید. فایل `keystore.properties` فقط روی runner ساخته می‌شود. Release بدون این مقادیر عمداً شکست می‌خورد و APK منتشر نمی‌کند.

## استفاده

در اولین اجرا نمونه در دیتابیس ساخته می‌شود. در صفحهٔ پروژه‌ها می‌توان پروژهٔ خالی ساخت یا نمونه را گشود. از ویرایشگر گره اضافه و انتخاب/جابجا کنید؛ برای اتصال، مبدأ را انتخاب کرده «ارتباط از گره انتخابی» و سپس مقصد را بزنید. پنل انتخاب برای پارامترها، قوانین، تکثیر، حذف و پاک‌کردن ارتباط‌هاست. در داشبورد مدت و seed را تغییر دهید. صفحهٔ اجرا دکمهٔ «گام بعد» و «ادامه / اجرا» دارد؛ «توقف» ادامهٔ همان موتور را حفظ می‌کند. داده‌ها به‌صورت خودکار در Room ذخیره می‌شوند. «پشتیبان / ورود و خروج» از انتخاب‌گر فایل سیستم استفاده می‌کند.
